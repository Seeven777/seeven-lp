# SEE7VEN V10.4 — Mobile Flow

## Objetivo

Corrigir os problemas observados em iPhone e reduzir a repetição de mensagens entre Hero, capacidades, Presence System, soluções e contato.

## Principais mudanças

- Hero mobile reduzido de uma narrativa longa para uma progressão mais rápida;
- orbit mobile limitado ao viewport, sem labels vazando lateralmente;
- header mobile com comportamento hide-on-scroll;
- Capability Universe com tabs compactas e card menor;
- Presence System mobile deixou de ser sticky de ~3 telas e virou seletor tátil com exemplo real;
- Selected Work virou carrossel horizontal com scroll-snap no mobile;
- arquivo de marcas virou índice compacto no mobile;
- Bento mobile mais curto, mantendo o raciocínio visual;
- soluções por problema não repetem o problema no painel de resposta;
- Motion virou rail horizontal no mobile;
- prova digital/físico virou galeria swipeável;
- parceiros deixaram de usar cards gigantes vazios no mobile e passaram a usar rail compacto;
- CTA final removeu a segunda lista de serviços; as escolhas ficam no Brief;
- Brief mobile usa duas colunas para reduzir altura;
- touch targets, scroll-snap, overscroll e barras de rolagem foram refinados.

## Infraestrutura

- Vercel preservado;
- Supabase preservado;
- `/admin` preservado;
- schema V8 preservado;
- nenhuma migration nova necessária;
- 25 parceiros continuam disponíveis via fallback/CMS.
