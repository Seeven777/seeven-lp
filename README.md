# Seeven Projects — Landing Page

## Rodar no Windows

Abra o PowerShell dentro desta pasta:

```powershell
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).

## Antes de publicar
1. Troque o número do WhatsApp em `src/main.jsx`.
2. Substitua o monograma `V` do cabeçalho pelo arquivo oficial da logo da Seeven, se desejar.
3. Revise os números do case do Sindpetshop-SP antes de publicar.
4. Revise os links dos clientes.
5. Rode `npm run build` para testar a versão de produção.
